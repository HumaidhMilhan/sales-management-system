# Nexus Retail - Frontend

A comprehensive retail management suite featuring an Admin Dashboard for analytics and inventory control, alongside a Salesman portal with POS capabilities.

## Tech Stack

- **React 19** with TypeScript
- **Vite** for development and build
- **Tailwind CSS** (via CDN) for styling
- **React Router** for navigation
- **Lucide React** for icons

## Available Scripts

### `npm run dev`

Runs the app in development mode at [http://localhost:3000](http://localhost:3000).

### `npm run build`

Builds the app for production to the `dist` folder.

### `npm run preview`

Previews the production build locally.

## Features

- **Login** — Role-based login (Admin / Salesman)
- **Admin Dashboard** — Sales stats, expired product alerts, revenue charts, top salesmen
- **Inventory** — Product listing with search, filtering, and CRUD actions
- **Salesmen Management** — Add, edit, activate/deactivate salesmen
- **Reports** — Sales trends, invoices, expiry alerts
- **Branding** — Customize shop name, logo, and theme colors
- **Salesman Dashboard** — Quick sale access, daily stats, expiry alerts, sales history
- **POS** — Product grid, cart management, checkout
